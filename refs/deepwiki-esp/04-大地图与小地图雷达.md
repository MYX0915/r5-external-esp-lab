# 4. 大地图与小地图雷达

页面描述了在两种战术界面中额外标记敌人、队友及其他被跟踪对象的功能。两种界面采用不同的位置参照：

| 界面 | 页面描述 |
| --- | --- |
| HUD 小地图 | 比较本地玩家和目标的位置，以玩家为参照更新小地图边界内的图标。 |
| 展开的全屏地图 | 以对象在游戏世界中的绝对位置为依据，在全屏地图上放置标记。 |

DeepWiki 还声称，全屏地图上的标记能够显示原本受地图迷雾或视线条件限制的信息。这是页面中的说法，不代表已核实游戏内行为。
