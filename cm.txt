实现实测验证后的完整 Glow 序列 + glowcolor 颜色命令

依据今天实测确认的写入序列（UC 公开文档缺失 fadeDuration）:
  +0x2A0 contexts[0] = 样式行号（必须 postProcess=1）
  +0x2A8 focused     = 1
  +0x2AC fadeDuration= 1.0f    ← 关键：为 0 时渲染管线直接丢弃，无轮廓
  +0x2B4 fadeParity  ^= 1      ← 仅开关瞬间翻转，tick 不触碰

驱动命令:
  glow 0x<实体> <row>       开启保活
  glowoff                   关闭
  glowcolor <row> <r> <g> <b> 修改样式表 RGB
  loot                      扫描 prop_survival / prop_death_box

glowcolor 实现:
  row 地址 = *(module + 0x72BE6C0) + row*0x34
  +0x04 R / +0x08 G / +0x0C B（float，0..1）

实测结论（本版本）:
  1. postProcess=1 的样式行才渲染穿墙剪影轮廓（row50 有，row2 无）
  2. fadeDuration 必须非 0
  3. parity 高频翻转会导致失效
  4. loot / npc_dummie 写入字段后无轮廓（ModelInstance 不进渲染队列）
  5. 地面物品紫/橙发光是材质效果，独立于 Highlight 系统
