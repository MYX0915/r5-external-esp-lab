重大发现：差分实验一直跑错了对象集 + 驱动过滤改为可切换

问题:
  训练场 3 个机器人(7m/17m/22m)，feed count=0，差分抓不到任何变化

根因:
  第 76 节为消除"道具也画框"加的 vtable 过滤：
    if (wantVt) { if (vt != wantVt) continue; }
  只收录与本地玩家同 vtable 的实体
  → 真人玩家收录，AI 机器人/训练假人全部被排除
  → feed 在训练场恒为 0
  → 此前多轮差分（含"靠近闪光"全量 dump）全部跑错了对象集

修复:
  驱动新增运行时模式
    mode 0  仅玩家（同 vtable 过滤生效）
    mode 1  全部实体（不过滤，默认）
  RebuildEntAddrs 中过滤改为:
    if (wantVt && g_espMode == 0) { ... }
  请求命令 mode 0 / mode 1，日志输出当前模式

驱动命令清单（bin\mdump.sys 05:45:59）:
  dump / p 探针 / w 写入（支持多条打包）/ wl 导出实体地址
  mode 模式切换 / ent 按类列举 / cls 类普查 / sig 特征扫描
  bones 骨骼 / heap 堆快照
