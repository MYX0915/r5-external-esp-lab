SkyNade 双解求解 + 鼠标闭环实测通过

双解求解器:
  A = D/t, B = (dh + 0.5gt²)/t
  reqV = sqrt(A²+B²), base = atan2(B,A)
  phi = acos(reqV/v0)
  LOW = base - phi, HIGH = base + phi

三个关键约束（实测发现）:
  1. 游戏 pitch 限制 ±89，HIGH 超限必须退回 LOW
  2. reqV > v0 时无解，退化为 base 角（最远射程角）
  3. V 不是越大越好：V 越大 phi 越大，HIGH 越容易超 90
     V=1600 全部只能低抛；V=1550 在 30~35 米全部高抛可用

鼠标闭环实测:
  yaw   1.17 → -36.35（目标 -35.29）
  pitch -59.16 → -83.49（目标 -83.50）
  22 步约 0.4 秒，误差 < 0.1 度
  双向（上抬/下压）均精确

三个曾经的误判与修复:
  抬不到参考线高度 → HIGH>90 被夹 → 自动退回 LOW
  完全不动         → reqV>vnow 无解 → 退化 base 角
  抬到一半卡住     → 光标撞边 raw input 归零 → 每次回中

焦点问题:
  游戏失焦时 mouse_event 完全无效
  测试时需先点游戏画面再按 Shift+左键
