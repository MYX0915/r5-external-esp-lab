对局 ESP 失效根因：两个不同的玩家类 + 距离上限

根因一：虚表白名单指向训练场假人类
  驱动自动设 g_vtExtra = module + 0x30E9330（训练场假人类）
  对局真实玩家类是 module + 0x316930（类普查 64 个实例）
  另有玩家状态类（18 实例，有血量无坐标）
  手动 vt2 到正确类后：wl 从 1 → 57，FEED 立刻 24 个实体

根因二：190 米距离上限
  if (d2 > 100000000.0f)  // 190m
  对局实测：最近 53m、中位 100m、最远 608m
  190m 内 56 个，1100m 内 64 个
  训练假人全在 100m 内，所以一直没暴露

修复：
  g_vtExtra  = module + 0x30E9330（训练场假人）
  g_vtExtra2 = module + 0x316930（对局玩家）
  距离上限 190m → 1100m
  坐标范围 ±40000 → ±60000

敌方血量不可获取（Apex 不同步敌方血量）
  对局玩家类 +0x330/+0x340 恒为 0
  ⇒ 敌人只能画框+距离+描边，血条只有假人/可观测实体

教训：训练场验证通过 ≠ 对局可用
